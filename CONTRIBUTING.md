# Contributing / 贡献说明

## English

Use an issue or pull request to describe a concrete research-workflow problem, the intended behavior, and why the change improves a decision or output. Prefer focused improvements over adding universal rules for a single case. Contributions may address question framing, evidence handling, disciplinary adaptation, writing, translation, or checks.

Keep English and Chinese modules, defaults, and exceptions aligned; natural wording need not be literal translation. Update Skill routing, usage, and portable guides when affected. Run the build and structural checks described in the [maintenance guide](maintenance-guide-en.md). Report what was actually tested; passing a file check is not a behavioral evaluation.

Do not submit private conversations, unpublished questions, lab details, proposal material, personal data, credentials, or research results—even anonymized—without explicit permission for publication. This release has no public examples directory. If examples are considered later, use separately approved synthetic or suitably licensed public teaching material.

Separate inspiration from copied or adapted third-party material. Check licenses and preserve attribution before including the latter. Contributions to this repository are provided under its [MIT license](LICENSE); do not submit material you cannot license on those terms.

## 中文

通过 issue 或 pull request 说明具体使用问题、预期行为以及改动怎样改善判断或产物。优先做有依据的局部修订，不把单一情境扩大成普遍禁令。可改进问题构建、证据处理、学科适配、写作、翻译与检查。

中英文模块、默认行为与例外保持一致，表达不必逐字翻译。同步受影响的路由、使用说明和完整引导，按[维护指南](maintenance-guide-zh.md)执行构建与结构检查。如实说明实际测试范围；文件检查通过不等于行为验证。

不得提交私人聊天、未公开选题、实验室信息、申报材料、个人数据、凭据或研究结果；匿名化不构成公开许可。本版不含公开 examples。将来需要案例时，单独确认完全合成或具有合适许可的公开教学材料。

区分设计启发与直接复制/改编内容，后者必须先核许可证并保留署名。贡献按本仓库 MIT 许可提供，请勿提交无权按此许可分发的材料。
