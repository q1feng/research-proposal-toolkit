# 使用说明

[首页](../README-zh.md) · [English](../en/usage.md)

## 免安装

上传[完整引导](proposal-guide.md)并说明观察/想法、当前材料、可用条件与本轮需求。不必先有最终题目，不必一次填完所有信息。单文件包含全部规则；助手不能写文件时请其输出可保存的 Markdown。云端助手不能自动访问本地路径，需实际提供文件。

## 安装 Skill

将本目录中的完整 `research-proposal-toolkit-zh/` 文件夹放入客户端支持的 Skill 目录，保留 SKILL.md、agents 和 references。不要只复制入口文件。不同客户端的安装位置和发现机制以其说明为准；本包不自动修改全局配置。

调用：`使用 $research-proposal-toolkit-zh，基于我的材料完成当前阶段，并保持研究决定与证据边界。`

中英文名称不同，可同时安装。若无法识别，可明确要求读取[入口](research-proposal-toolkit-zh/SKILL.md)及其引用资料，或改用免安装版。首次使用不需要特定模型、密钥或其他 Skill。

## 组合自己的工作流

本包吸纳了文献综述与开题工作 Skill 的一些核心机制，同时把按需组合视为核心理念：鼓励用户根据学科、研究阶段和交付需求，搜索并选择适合自己的文献检索、研究框架修订、学术润色与论文写作 Skill，形成专属工作流。也可探索接入作图与 PPT 制作 Skill；这些扩展目前尚未经过本包的集成测试。额外 Skill 是可选项，不安装也能使用本包或完整引导。

首次调用 Skill 或上传 proposal-guide.md 时，助手应简要提示这些选择，并沿用你已有的工具偏好。可直接说明要接入的 Skill，或请助手帮助查找；也可先用本包继续当前工作，不必先选齐工具。

## 接续工作

已有文件时说明位置并沿用；新论文到来时检查受影响的基线、主张和方向，不只追加摘要；反馈修改应解释依据与代价，已经选定的方向直接落实。默认输出文件名不带语言后缀，需要双语产物时分目录。

未知证据如实标记；不把框架、草稿或脚本运行成功当研究结论。实际检索、分析和排版范围由用户请求与可用工具决定。

本包已包含 Forge 核心。默认四份产物：research-framework.md、citation-ledger.md、literature-review.md、research-proposal.md。可只做一个阶段或按指定顺序成稿；[引用模板](citation-audit-template.md)可选复制。
