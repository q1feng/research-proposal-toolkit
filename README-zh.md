# Research Proposal Toolkit｜研究开题工作流

[English](README.md) | 简体中文

> **从研究问题，到完整开题工作流。**

Research Proposal Toolkit 基于 [Research Question Forge](https://github.com/q1feng/research-question-forge)，将早期想法发展为有证据基础的文献综述与完整开题草稿，连接问题形成、文献综合、证据管理、研究设计和迭代修订。

可以整包使用，也可作为组合自己科研工作流的参考架构。

[免安装开始](zh/proposal-guide.md) · [安装 Skill](zh/usage.md) · [English guide](en/usage.md)

## 这是什么

面向研究生的开题引导流程，默认硕士尺度，可适配其他学位和学科。从观察、已有框架或待修改草稿均可进入，学校规范优先。

交付目标是有来源依据、可独立阅读的正文，不只是表格和论文摘要集合。用户可以请求完整链路或其中一个阶段。

## 基于 Research Question Forge

Forge 提供问题形成、文献反馈、扩展与拆分，以及结构化研究框架。Toolkit 继续连接文献综合、引用审计、研究设计和综述/开题联动写作。

本仓库是 Forge 的一种完整工作流实现，不是唯一用途。为便于独立使用，已内置带同步记录的核心快照，无需额外安装 Forge。

## 完整工作流

```text
观察／想法 → Forge → 研究框架
                         ↕
                 检索／阅读 ↔ 证据审计
                         ↕
                   文献综合 ↔ 研究设计
                         ↓
                   文献综述 ↔ 开题报告

新证据／反馈 ──→ 问题抽象（Forge）
            ├─→ 问题拓展／问题拆分（Forge）
            └─→ 研究框架 → 综述与开题联动修订
            ╌╌→ 反思观察方式、科研想法与问题形成
```

实线表示研究工作中的直接推进与修订：新证据／反馈可同时调整问题抽象、问题拓展／拆分和研究框架。虚线表示更深层的认识论反思：我们为何注意这些现象、如何观察与解释、哪些前提塑造了科研想法，以及如何从观察提出问题。两类反馈都可反复发生，不必等到框架或草稿完成。

文献、条件或导师反馈改变依据时，可以返回前面的环节。它不是输入题目后一次性生成报告的工具。

已有同职责文件沿用，详细任务书按需展开。综述默认正文约 10 页 A4，不含前置页、书目和审计；实际页数须在排版后核对。

## 两份草稿怎样保持一致

共享研究问题、定义、最近似工作、证据、未决问题和方法假设。综述形成领域认识，开题发展具体拟研究方案；背景与比较可以复用，但须保留来源和限定。

实质变化需检查框架、引用记录和另一份草稿。稳定文献 ID 不随正文编号变化丢失。不能在改写中将计划变成成果。

## 迭代研究与写作

新文献检验问题与比较基线。先综合后写作，先结构与证据后润色；综述解释差异并形成有边界的判断，开题建立问题—方法—证据的联系，不堆摘要或实施步骤。

尊重用户指定的次序，包括先综述、继续阅读调整、再开题。实质转向先说明方案及返工成本，由研究者选择。

## 直接使用，或组合自己的流程

本包吸纳了文献综述与开题工作 Skill 的一些核心机制，同时把按需组合视为核心理念：鼓励用户根据学科、研究阶段和交付需求，搜索并选择适合自己的文献检索、研究框架修订、学术润色与论文写作 Skill，形成专属工作流。也可探索接入作图与 PPT 制作 Skill；这些扩展目前尚未经过本包的集成测试。额外 Skill 是可选项，不安装也能使用本包或完整引导。

可替换检索、精读、引用管理、研究设计、代码、分析、写作或排版环节。交接携带问题、已确认条件、来源要求、未知项与允许范围；不要求特定模型、API 密钥或社区 Skill 系列。

不安装也可把完整引导作为工作流设计参考。检索、计算与格式导出能力取决于宿主环境。

## 快速开始

上传[完整引导](zh/proposal-guide.md)，或把完整[中文 Skill 文件夹](zh/research-proposal-toolkit-zh/SKILL.md)放入客户端支持的目录，保留 references 与元数据。

> 使用 $research-proposal-toolkit-zh。我的学科和学位是……，想法、文献与条件是……。请先构建问题并比较文献，再写独立综述，随后形成开题；涉及方向的实质调整先与我讨论。

可附学校要求与风格样稿。详见[使用说明](zh/usage.md)和可选的[引用审计模板](zh/citation-audit-template.md)。

## 研究原则

- 不编造来源、阅读、结果、条件、成果或创新。
- 区分直接证据、间接支撑、推断与拟开展工作。
- 保留反证、学科差异和研究者决定权。
- 工作提示留内部记录，真实学术不确定性留在论证中。
- 草稿完整不表示研究完成，仍需人工审查。
